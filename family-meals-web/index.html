① 注册 Supabase（免费）

打开 supabase.com → Sign up → 新建 Project（选 Free 免费计划）

② 建表

Supabase 左侧 SQL Editor → 粘贴项目里 supabase/schema.sql 的内容 → Run

③ 创建图片存储

左侧 Storage → New bucket → 名称填 dish-images → 勾选 Public → 在 bucket Policies 允许公开读写（详见 README）
